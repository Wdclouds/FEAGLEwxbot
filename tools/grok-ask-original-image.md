## 实测事实（已确认，不用验证）

1. 图片消息对象 `field_content` 是 XML：
   `<img aeskey="be3235a8...f3" encryver="1" cdnthumbaeskey="同aeskey" cdnthumburl="305f020100044b304902010002046ca1d9a6..." cdnthumbheight="340" cdnthumbwidth="497" cdnmidimgurl="同上hex" length="38658" md5="2f823507..." hevc_mid_size="22891"/>`
   ——`cdnthumburl`/`cdnmidimgurl` 是 hex，解码后是 **ASN.1/DER 结构**（`30 5f 02 01 00 04 4b 30 49 02 01 00 02 04 6c a1 d9 a6 ...`），内嵌 IPv4 `108.161.217.166` + UUID `b9ff2fcf5-3531-482f-99c8-0a5deeb5545a`。这是微信新 CDN（mmtls）定位信息，**不是 HTTP URL**。
2. 服务器（国内阿里云）curl 该 IP 直连失败——mmtls 私有协议，服务器侧下载已死。
3. 本地缩略图：`/data/data/com.tencent.mm/MicroMsg/<用户目录>/image2/<前2>/<次2>/th_<32hex>`（无扩展名，**已解密** JPEG，497×340，6.8KB）。原图**默认不下载**，用户「点开大图」才下载；「自动下载」设置实测对新图无效。
4. `image2/.ref/` 目录存在，内有 UUID 命名文件（`d/e15aadc4-d81b-4baf-862b-5bd46d826cd3` 这种），疑似 CDN 引用/缓存。
5. lvbuffer（335B PB）无 http 明文。
6. 原图大小 38KB（length=38658），md5 已知。
7. dex 字符串明文，可搜（rcontact/@chatroom 都能搜到）。DexKit 运行时搜索不可用。

## 已排除

❌ 服务器直连 CDN（mmtls） ❌ 微信自动下载设置 ❌ 读数据库 ❌ DexKit ❌ 手动点图
